# ChairSync - Barber Management System

## Problem Statement

Many barber shops still rely on manual methods to manage customers, waiting queues, and chair availability. Customers often arrive without knowing whether chairs are available, leading to long waiting times, overcrowding, and confusion about the order of service. Staff must manually remember customer turns, assign chairs, and track which barber is serving which customer, increasing the chance of mistakes and reducing operational efficiency. Existing solutions are often expensive or include unnecessary features for small and medium-sized barber shops.

ChairSync addresses this problem by providing a digital queue and chair management system that enables staff to register customers, maintain an organized waiting queue, monitor real-time chair availability, assign customers to available chairs, and update service status throughout the haircut process. The system helps reduce waiting time, eliminates manual record-keeping, improves service organization, and provides a smoother experience for both customers and barbers.

## Core Features
- **Customer Registration**: Easily add walk-in or booked customers to the system.
- **Digital Queue Management**: Keep track of who is next in line without manual lists.
- **Real-Time Chair Monitoring**: See which chairs are occupied, available, or out of service.
- **Customer Assignment**: Seamlessly assign customers from the queue to available chairs.
- **Service Status Updates**: Track a haircut's progress from waiting, to seated, to completed.

## Tech Stack
- **Frontend**: React + Vite 
- **Backend**: .NET Core (Web API)
